# Repository Guidance

## Validate Changes

Run `make test` before opening or updating a pull request.

## Rabbit CI Context

`.rabbit/repo.yaml` is generated by `rabbit.ci`; do not edit it by hand.

When reviewing or changing GitHub workflows, branch protection, environments,
or repository-level Actions configuration, run `rabbit.ci` and include the
resulting `.rabbit/repo.yaml` update in the same change. A refresh is not
needed for action implementation or documentation changes that do not affect
that captured GitHub configuration.
